````md id="day011_doc"
```python

````

## ✔ 2. Sum of Elements

```python id="vlj1n2"

print(sum(l))
```

---

## ✔ 3. Maximum Element

```python id="ihhj51"

print(max(l))
```

---

## ✔ 4. Minimum Element

```python id="w40fpx"

```

---

## ✔ 5. Count Occurrences of an Element

```python id="g0qpx5"

```

---

## ✔ 6. Check if Element Exists

```python id="d7h97y"

```

## ✔ 7. Reverse a List

```python id="48g0xy"

```

## ✔ 8. Find Second Largest Element

```python id="g75o7v"

```


