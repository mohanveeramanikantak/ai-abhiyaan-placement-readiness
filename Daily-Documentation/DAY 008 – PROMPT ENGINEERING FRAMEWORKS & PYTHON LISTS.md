# 📘 1. UNIVERSAL PROMPT TEMPLATE

## ✔ Prompt Structure

```text
Role + Task + Context + Constraint + Output Format + Ask me back any questions you have
````

### ✔ Example

```text
Act as an AI Engineer and create a roadmap for learning Prompt Engineering for beginners. 
Use simple English, include projects, and provide the output in markdown format.
Ask me back any questions if needed.
```

# 📘 2. ROLE-BASED PROMPTING (ACT-AS TECHNIQUE)

## ✔ Structure

```text
Act as [Role]
```

### ✔ Example

```text

```

### ✔ Learning

Role-based prompts improve:

* Output quality
* Domain expertise simulation
* Structured responses

# 📘 3. PROMPT–RESPONSE LOOP

## ✔ Understanding

AI prompting is an iterative process.

### 📌 Flow

Prompt → Response → Improve Prompt → Better Response

### ✔ Key Learning

Better iteration leads to better outputs.

---

# 📘 4. 4W + 1H PROMPT FRAMEWORK

## ✔ Framework Structure

* What → Topic
* Why → Reason
* Where → Location
* Who → Audience/Role
* How → Output Format

---

## ✔ Template

```text
Act as [Role] and craft a presentation on [Topic] to explain [Why] for [Where], tailored to [Who/Target Audience], and deliver the final output as [How/Output Format].
```

---

# 📘 5. STEP-BACK PROMPT TECHNIQUE

## ✔ Learning

Instead of directly solving a problem:

* Step back
* Understand the broader context
* Break down the problem
* Then generate the solution

### ✔ Benefit

Improves:

* Logical reasoning
* Structured outputs
* AI response quality

# 📘 8. LIST TRAVERSAL

## ✔ First Level Traversal

```python
l=[10,20,30,40]

for i in l:
    print(i)
```

---

## ✔ Second Level Traversal

```python
l=[[1,2],[3,4]]

for i in l:
    for j in i:
        print(j)
```

# 📘 9. PRACTICE PROBLEMS

## ✔ Problem 1 – Sum of List Elements

```python
l=[1,2,3,4]
total=0

for i in l:
    total+=i

print(total)
```

---

## ✔ Problem 2 – Find Maximum Element

```python
l=[10,50,20,5]

max=l[0]

for i in l:
    if i>max:
        max=i

print(max)
```

---

## ✔ Problem 3 – Reverse a List

```python
l=[1,2,3,4]

print(l[::-1])
```

---

## ✔ Problem 4 – Count Even Numbers

```python
l=[1,2,3,4,5,6]

count=0

for i in l:
    if i%2==0:
        count+=1

print(count)
```
