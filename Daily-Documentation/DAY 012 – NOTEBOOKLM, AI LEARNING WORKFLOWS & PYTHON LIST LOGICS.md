# 📘 7. SECOND LARGEST ELEMENT PROGRAM

```python
l=[6,5,9,2,99,55,67,49,58]

f=max(l[0],l[1])
s=min(l[0],l[1])

n=len(l)

for i in range(2,n):
    if l[i]>f:
        s=f
        f=l[i]
    elif l[i]>s:
        s=l[i]

print(s)
```

### ✔ Concepts Used

* List traversal
* Maximum element logic
* Second largest element finding

---

# 📘 8. SWAPPING ELEMENTS PROGRAM

```python id="5o79pv"
a = [4,2,3,5,6,1]

n=len(a)

for i in range(0,n-1):
    if a[i]>a[i+1]:

        temp=a[i]
        a[i]=a[i+1]
        a[i+1]=temp

print(a)
```

### ✔ Concepts Used

* Swapping logic
* Conditional comparison
* Basic sorting concepts

# 📘 10. SECOND LARGEST ELEMENT – ALTERNATE PROGRAM

```python id="28bg6s"
l = [4, 8, 12, 14, 13, 6]

F = max(l[0], l[1])      # Largest
S = min(l[0], l[1])      # Second Largest

n = len(l)

for i in range(2, n):
    if l[i] > F:
        S = F
        F = l[i]

    elif l[i] > S:
        S = l[i]

print("Second largest element:", S)
```
